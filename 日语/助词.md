# が
## 格助词
1. 提示主语。表示客观现象、事物的状态、性质等,或表示话题中首次出现的事物。
    ```
    △この大学に留学生がいますか。【2009年真題】/这所大学里有留学生吗?
    △昨日は天気がよくなかったですね。【2008年真題】/昨天天气不好呢。
    △このレストランはいつもたくさん人が並んでいますね。【2006年真题】/这家餐厅经常会排队排着很多人呢。
    △あ、あそこで鳥が鳴いていますよ。【2007年真題】/啊,那边有鸟儿在叫。
    △窓が全部開けてあります。【2009年真题】/窗户全都开着了。
    △あの部屋が日本語の教室です。【2007年真题】/那个房间是日语教室。
    ```

2. 表示整体中的一部分或从句中的主语。
    ```
    △兄は背が高いです。【2008年真題】/哥哥个子高。
    △母が作るサンドイッチは美味しいです。【2008年真題】/妈妈做的三明治很好吃。
    △トイレの掃除はいつもわたしがします。【2008年真題】/厕所的打扫一直是我在做。
    △家族が出かけたあとで、部屋の掃除をします。【2009年真題】/家人都出门后,再打扫屋子。
    ```

3. 表示疑问句中的主语。
    ```
    △遊びに行きましょう。どこがいいですか。【2009年真題】一起去玩吧。去哪里好呢?
    △パーティーはいつがいいですか。【2007年真题/聚会定在什么时候好呢?
    △どの人が山下さんですか。【2006年真題】/哪位是山下先生(小姐)?
    ```

4. 表示好恶、希望、技能好坏等的对象。
    ```
    △昨日会った人の名前が分かりません。【2009年真題】/我不知道昨天见到的人叫什么。
    △兄はサッカーが好きです。【2006年真題】/哥哥喜欢踢足球。
    △わたしはカメラがほしいです。【2008年真題】/我想要照相机。
    △田中さんは多分歌が上手でしょう。【2008年真题/田中唱歌应该还不错吧。
    ```
## 接续助词、终助词
1. 句子的简体形/敬体形+が
    * 表示逆接,即后项事物的出现和一般常理不符。
    ```
    △ 30 分ぐらい待ちましたが、バスは来ませんでした。【2003年真题1/等了大约30分钟,可是公交车也没来。
    △この部屋は新しくありませんが、きれいです。【2000年真题】/这个房间不新,却很干净。
    ```

2. 表示前后两个句子互为对照。
    ```
    △山田さんはテニスはしますが、ゴルフはしません。【2007年真題】/山田打网球,不过不打高尔夫。
    △わたしはよく旅行をしますが、兄はあまりしません。【2008年真题/我经常去旅游,不过哥哥不太去。
    ```

3. 用于引出话题。
    ```
    △すみませんが、少し静かにしてください。【2002年真題】/不好意思,请稍微安静点。 
    △もしもし、すみませんが、山下さんをお願いします。【2001年真题】/喂,麻烦能让山下先生(小姐)接电话吗?
    ```

# か
## 并列助词、提示助词
1. **表示从两个或三个事物中选取一个,表示选择。**
    ```
    △今日か明日、一緒にご飯を食べませんか。【2009年真题今天或明天,一起吃个饭吧。
    △この料理は牛肉か豚肉を使います。【2007年真题】/做这道菜要用牛肉或猪肉。
    △明日雨が降るか降らないかは分かりません。【2005年真題】/不知道明天下不下雨。
    ```

2. 表示不确定或不特指的意思。
    ```
    △誰か手伝ってください。【2007年真题】/谁来帮帮我。
    △何か運動をしていますか。【2007年真题1/你有做什么运动吗?
    △いつかまた日本へ来たいです。【2008年真題】/以后还想再来日本。
    △何か飲みながら、話をしましょう。【2008年真题】/边喝点什么东西边聊吧。
    ```

## 接续助词、终助词
### 各种词类基本形/句子的简体形・敬体形/助词  + か
* 「か」作为终助词,读升调,可表示疑问、不确定等语气;读降调,可表示惊讶、感叹等语气。
* 另外可以用「こですか、~ですか」或「~ますか、~ますか」的句型表示选择疑问
```
△その本をどこで買ったか覚えていますか。【2009年真题/还记得那本书是在哪里买的吗?
△昨日のパーティーで何をしましたか。【2006年真題】/(你)在昨天的聚会上做仕么了?
△また遅刻ですか。又迟到了!
△郵便局は、レストランの右ですか、左ですか。 【2000年真題】/邮局是在餐厅的右边还是左边?
```


# は
## 并列助词、提示助词
1. 「は」 用来提示主题,并对主题进行说明和判断。
    ```
    △わたしの部屋はあまりきれいじゃありません。【2006年真題】/我的房间不太整洁。
    △一番大変な仕事は何ですか。【2007年真题】/最困难的工作是什么?
    ```

2. 「...は...が...」的句型可用来说明主题的某种状态。
    ```
    △兄は背が高いです。【2007年真题】/哥哥个子高。
    △明日は雪が降るでしょう。【2006年真題】/明天会下雪吧。
    ```

3. 「...は...(が)、...は...」的句型可用来进行两种事物的比较。
    ```
    △山田さんはテニスはしますが、ゴルフはしません。【2007年真題】/山田打网球,但不打高尔夫。
    ```

# は和が的区別
1. 提示主題用 「は」,提示主语用「が」。
    ```
    △象は鼻が長いです。/大象鼻子长。
    ```

2. **对主题进行说明判断时用「は」,陈述眼前看到的、听到的、实际感受到的事情时用「が」。**
    ```
    △東北地方の雪は多いです。/东北地区雪下得多。
    △今、雪が降っています。現在正在下雪。
    ```

3. **提示已知事物用 「は」、未知事物用「が」。**
    ```
    △ 机の上に日本語の教科書があります。それは王さんのです。/桌上有本日语教科书,那是小王的。
    △どの人が山下さんですか。【2006年真题】/哪位是山下先生(小姐)?
    ```

4. 「は」的指示范围涉及全句,即关联句末的谓语,可以说是句子的大主语;「が」可指示分句中的主语,也可以称作是此类句子的小主语。

    ```
    △先週は宿題が多くて大変でした。【2006年真題】/上周作业很多,忙死了。
    △母が作るサンドイッチは美味しいです。【2007年真题】/妈妈做的三明治很好吃。
    ```

# で
## 格助词
### 接续名词/数量词で
1. 表示动作进行的场所。
    ```
    △ここで写真を撮ってもいいですか。【2008年 题可以在这里拍照吗?
    △駅の近くの店でこれを買いました。【2007年真題】在车站附近的店里买了这个。
    ```

2. 表示手段、方式方法、工具等。
    ```
    △ナイフでパンを切りました。【2006年真题/用刀把面包切开了。
    △大きな声で話さないでください。【2009年真题】/请不要大声说话。
    △自転車で買い物に行きます。【2008年真題】/骑自行车去买东西。
    ```

3. 表示动作的基准或数量的合计等。
    ```
    △ノートは5冊で300円です。【2008年真题五本笔记本300日元。
    △病院へ一人で行きました。【2008年真題】一个人去了医院。
    △わたしの家族は、全部で8人です。【2000年真題】/我家总共八口人。
    ```

4. 表示原材料。
    ```
    △この料理は肉と野菜で作ります。【2001年真题/这道菜要用肉和蔬菜来做。
    ```

5. 表示范围。
    ```
    △この町で一番賑やかなのはこの辺です。【2009年真题1/这一带是这个小镇最热闹的地方
    △図書館では、静かに歩いてください。【2001年真題】/在图书馆走路时请放轻脚步声。
    ```

6. 表示原因、理由。
    ```
    △去年、仕事で外国へ行きました。【2009年真題】/去年因工作关系去了国外。
    △風邪で学校を休みました。【2009年真題】/因感冒没去学校。
    △昨日 弟は病気で学校を休みました。【2007年真題】/昨天弟弟因生病没去学校。
    ```

# て/で
## 接续助词、终助词
### 名词・な形容词词干+で     い形容词词干+く+て
1. 表示中顿。
    ```
    △ 妹は17歳で、学生です。【2007年真題】/我妹妹十七岁,是学生。
    △一昨日は雨で、昨日は雪でした。【2008年真題】/前天下雨,昨天下雪了。
    △この辺は夏は涼しくて、冬は暖かいです。【2009年真題】/这一带冬夏凉。
    ```

2. 表示并列。
    ```
    △わたしのアパートは静かでいいです。【2007年真题】/我住的公寓安静又舒适。
    ```

3. 表示轻微的原因。
    ```
    △この道は暗くて危ないです。【2008年真题/这条路很黑,有点危险。
    △先週は宿題が多くて大変でした。【2006年真题】/上周作业很多,真够。
    ```


# と
## 格助词
1. 表示共同进行某项动作、行为的对象,可以用 「と一緒に」的形式。
    ```
    △わたしはおじいさんとよく散歩をします。【2006年真題】/我经常和爷爷一起散步。
    △昨日誰と一緒に帰りましたか。【2008年真題】/昨天和谁一起回去的?
    ```

2. 表示和某人互相进行某事,此事必须有对方参与才能完成。
    ```
    △わたしは先生と30分話しました。【2007年真题】/我和老师谈了30分钟。
    △友だちと電話で話しました。【2002年真題】/和朋友通了电话。
    ```

3. 表示说话或引用的内容等。
    ```
    △この猫は何という名前ですか。【2008年真题】/这只猫叫什么名字?
    △漢字のテストは大変だったとみんな言っていました。【2008年真题】/大家都说汉字考试太难了。
    ```

## 并列助词、提示助词
1. 用来表示完全列举,一般在列举的事物数目不超过三个时使用。
    ```
    △この料理は肉と野菜で作ります。【2001年真題】/这道菜要用肉和蔬菜来做。
    ```

# や
## 并列助词、提示助词
1. 对于代表性事物的部分列举,或叫作不完全列举。构成句型为「...や...(や)...(など)」,后面的「や」 和 「など」 可省略,一般在所列举的事物数目超过三个时使用。
    ```
    △日曜日に掃除や洗濯をします。【2007年真题】/周日就在家打扫房间或洗衣服什么的。
    ```


# に
## 格助词
1. 表示事物存在或静态的动作、作用的场所。
    ```
    △学校のそばに郵便局があります。【2008年真題】/学校旁边有家邮局。
    △ 机の上に本が5冊あります。【2007年真題】/桌上有五本书。
    △ドアにカレンダーが貼ってあります。【2005年真題】/门上贴着日历。
    ```

2. 表示动作、作用的到达点、着落点等。
    ```
    △パーティーに日本人は一人も来ていません。【2009年真题】/没有一个日本人来参加聚会。
    △車の中に鍵を忘れました。【2008年真题】/把钥匙忘在车里了。
    △ここにかばんを置かないでください。【2007年真題】/不要把包放在这里。
    ```

3. 表示动作、作用的具体时间。
    ```
    △映画は何時に終わりますか。【2007年真题】/电影几点结束?
    △日曜日に掃除や洗濯をします。【2007年真題】/周日打扫房间、洗衣服什么的。
    ```

4. **表示动作、作用的目的。**
    ```
    △買いものに行くとき、バスに乗ります。【2009年真題】/去买东西的时候,坐公交车去。
    △明日わたしの部屋へ遊びに来ませんか。【2006年真题】/明天来我这房间吧?
    △図書館へ本を返しに行きます。【2002年真題】/去图书馆还书。
    ```

5. 表示动作、作用涉及的对象。
    ```
    △わたしは友だちに電話をしました。【2006年真題】/我给朋友打了电话。
    △分からないときは、先生に聞きます。【2006年真題】/不明白的时候,问老师。
    ```

6. 表示某一时间范围内的数量或次数。
    ```
    △父は一日に3回歯を磨きます。【2009年真题/爸爸一天刷三次牙。
    ```

# の
## 格助词
### 接续1 名词+の名词
1. 表示所属、性质、限定、同位语等。
    ```
    △日本の古い映画を見ました。【2009年真题】/看了日本的老电影。
    △息子の太郎は今年、 17歳です。我子太郎今年17岁。
    △その大きい荷物はわたしのです。【2005年真题】/那个大行李是我的。
    △この新聞は一昨日のだからもう要りません。【2001年真题】/这份报纸是前天的,所以已经不需要了。
    ```

### 接续2 な形容词词干+な / い形容词基本形 + の
    ```
    △この町で一番賑やかなのはこの辺です。【2009年真題】/这----带是这个小镇最热闹的地方
    △もうちょっと安いのを、見せてください。【2000年真题1/请让我看看再便宜一些的。
    ```

### 接续3 名词 + の

* 句子的修饰成分。

    ```
    △田中さんの来る日は火曜日です。【2007年真題】/田中周二来。
    ```

# を
## 格助词
1. 表示动作所涉及的对象,即通常所说的宾语。

    * 这种情况下,「を」后的动词为他动词。

    ```
    朝シャワーを浴びました。【2009年真題】/早上淋了浴。
    ```

2. 表示动作经过的场所。

    ```
    △この橋を渡って向こうに行きましょう。【2009年真題】/走过这座桥去对面吧。
    ```
    * 此类动词还有「歩く、泳ぐ、散歩する、飛ぶ、登る、走る、旅行する」等。

3. 表示动作的起点、出发点。

    ```
    △わたしは今日6時に会社を出ます。【2005年真题】/我今天六点离开公司。
    △7時に家を出ます。【2002年真题/七点从家里出门。
    ```
    * 此类动词还有「降りる、卒業する、立つ」等。


# しか
## 并列助词、提示助词
1. 「...しか (...)ない/ありません」的形式对事物的数量或事物本身进行限定,意为除此之外没有其他,表示事实和说话人的预期、希望有差距。

    * 句型含有讲话大感觉不满意的语感,所以一般用于消极场合

    ```
    △雪がたくさん降ったから、一人しか来ませんでした。【2005年真题1/因为下了大雪,所以只来了一个人。
    △去年の冬は雪が上回しが降りませんでした。【2001年真题去年冬天就下了一场雪。
    ```

# だけ
## 并列助词、提示助词
1. 可用于限定数量、时间、范围、程度等,包含说话人不满的语气很少,更多的是用于描述客观事实。

    ```
    △高いケーキをひとつだけ買いました。【2009年真题】/就买了一个昂贵的蛋糕
    △一人だけ早く帰りました。【2007年真题】/只有一个人提早回家了。
    △小川さんだけお酒を飲みます。【2002年真题只有小川喝酒。
    ```

# ても/でも
## 接续助词、终助词

1. 动词て形+も
    * 表示逆接,意为“即使………………,但是………………”。
    ```
    △この雑誌を見てもいいですか。【2009年真題】(我)能看一下这本杂志吗?
    △ここで写真を撮ってもいいですか。【2008年真题】/可以在这里拍照吗?
    △ここで休んでもいいですか。/在这里休息一下可以吗?
    ```

# から
## 接续助词、终助词

1. 句子的简体形/敬体形+から
    * 表示原因、理由。由 「から」 构成的原因、理由的句子,也可以先描述结果再阐述理由。
    * 由「から」表示的原因、理由主要是说话人的个人主观行为的理由,因此后面的句子也多数是表示说话人的请求、愿望、推测、主张等内容。

    ```
    △今日はいい天気だから、洗濯しましょう。【2009年真题】/今天是好天气,那就洗衣服吧。
    △たくさんコピーしたから、紙があまりありません。【2009年真题】/因为复印了很多,所以纸所剩无几了。
    △忙しいから、ご飯を食べる時間がありません。【2008年真題】/太忙了,连吃饭的时间都没有。
    △寒くなりましたから、セーターが要ります。【2008年真題】/天气变冷了,所以需要毛衣。
    △電車が止まりました。雪がたくさん降ったからです。【2007年真题1/电车停了,因为雪下得太大了。
    ```

# ので
## 接续助词、终助词

1. 名词・な形容詞な形/い形容词基本形/动词基本形/各词类た形/句子的简体形・敬体形 **+** ので
    * 表示原因、理由,一般用于前项和后项是比较自然的因果关系的场合,语气比「から」委婉.
    * 「ので」 所列举的原因、理由比较客观,也是大家都认可的原因。后项不能用命令、禁止的表达方式。
    ```
    △主人が今出張中なので、うちにはいません。我老公去出差了,所以不在家。
    △今度の試験がとても難しかったので、合格しませんでした。/这次考试太难了,所以没有及格。
    △風邪を引いたので、病院へ行きました。/感冒了,所以去医院了。
    △用事があるので、お先に失礼します。/我还有点事,所以就先告辞了。
    ```

# たり
## 接续助词、终助词

### 动词た形+り、动词た形+り+する
1. 列举两个或两个以上的动作,暗示还有其他同类动作。
    ```
    △図書館で本を読んだり勉強したりします。【2008年真题在图书馆看看书、学习一下什么的。
    ```

2. 表示动作的反复进行。
    * 前后应该是两个意思对立的动词。
    ```
    △学生たちは、教室を出たり入ったりしています。/学生们从教室进进出出。
    ```

3. 用 「...たり(など)する」的形式,只举出一个代表性的例子,暗示还有其他的动作。
    ```
    △みの日は映画を見たり(など)しています。/休息的时候就看看电影么的。
    ```
