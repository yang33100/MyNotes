# 名词+をください
* 更礼貌的説法是「~をくださいませんか」。
```
△すみません、お水をください。【2006年真題】/不好意思,请给我水。
```

# ~てください
* 动词て形+ください
* 动词ない形+ないでください
*  ~てくださいませんか / ないでくださいませんか

**表示面对面的请求、命令或指示对方做某事、不做某事,意为“请(不要)...”。**

**虽然表示礼貌的请求,但因其本身也带有命令的口气,所以一般不能对上司、长辈等需尊敬的人使用。**

```
△高いですね。もっと安くしてください。【2009年真題】/太贵了,请再给我便宜些吧。
```

# ~ませんか
* 动詞ます形+ませんか
```
△今日か明日、一緒にご飯を食べませんか。【2009年真題】/今天或明天,一起吃个饭吧。
```

# ~ましょう
* 动词ます形+ましょう
* 「~ましょうか」也可用来表示邀请,语气比 「~ましょう」 更委婉。
```
△この橋を渡って向こうに行きましょう。【2009年真题1/过了这座桥去对面吧。
△今日はいい天気だから、洗濯しましょう。【2009年真題】/今天是好天气,洗衣服吧。
```

# ~たい
* 动词ます形+たい
* 问句「~たいですか」可用在第二、第三人称上。

**用于表示第一人称的愿望、想法。**

```
△いつかまた日本へ来たいです。【2008年真题以后想再来日本。
△今年の夏は海で泳ぎたいです。【2008年真题】/今年夏天想在海里游泳。
△わたしは外国で働きたい。【2006年真題】/我想在国外工作。
```

#  ~がほしい
* 名词+がほしい
* 疑问句 「~がほしいですか」也可用在第二、第三人称上。另外、「~たいですか」、~ほしいですか」一般不用于面对面询问上司、长辈等理应尊敬的人的愿望、欲望,否则会显得不是很礼貌。

**表示第一人称想要得到某种东西的愿望。**

```
△わたしは自転車がほしいです。【2007年真题我想要自行车。
△新しい洋服がほしいです。【2001年真題】/我想要新衣服。
```

# ~だろう / でしょう
* 动词基本形/ い形容词基本形 / な形容词词干 /名詞 + だろう / でしょう
* 常和确信程度不高的「たぶん、おそらく」等副词连用,表示说话人的主观推测。
* 与确信程度较高的「必ず、きっと」等副词连用,表示说话人较为肯定的判断。
```
△田中さんはたぶん歌が上手でしょう。【2008年真题田中唱歌应该很好听吧。
△明日はおそらく風が強いでしょう。/明天或许风会很大吧。
△明日はきっと雪が降るでしょう。/明天肯定会下雪吧。
```

# ~にする / くする
* な形容词词干/名词+にする
* い形容词词干くする

**表示人为地改变、改造,使其达到期望的结果。**

```

△すみませんが、少し静かにしてください。【2002年真題】/不好意思,请安静点。
△バナナを半分にして一緒に食べましょう。【2004年真题1/把香蕉分成两半一起吃吧。
△高いですね。もっと安くしてください。【2009年真题】/太贵了,请再便宜点。
△昼ご飯の時間をもっと遅くしませんか。【2005年真題】/把午饭时间再稍微推迟一点吧。

「~にする」还可以表示选择
△コーヒーにするか、紅茶にするか、早く教えてください。/你是选咖啡还是红茶,快告诉我。
```

#  ~になる / くなる
* 形容词词干/名词 + になる
* い形容词词干 + くなる

**表示事物自然而然的变化结果。**

```
△寿司が好きになりました。【2009年真題】/变得喜欢吃寿司了。
△12時になりました。昼ご飯の時間です。【2006年真題】/十二点了,到午饭时间了。
△大学の友達は、英語の先生になりました。【2005年真题大学时的朋友成为了一名英语老师。
△仕事が忙しくなりました。【2006年真題】/工作变忙了。
△たくさん歩いたから、足が痛くなりました。【2005年真題】/走了很多路,脚痛了。
```

# ~ている
* 动词て形+いる

**前接持续性动词,表示某动作正在进行,或表示平时反复进行的某种习惯性行为。**

```
△子どもたちが歌を上手に歌っています。【2009年真題】/孩子们娴熟地唱着歌
△何か運動をしていますか。【2007年真题】/你平时在做什么运动吗?
```

**前接瞬间动词,表示动作、作用完成后所呈现的状态,或其作用后的结果还保留着的状态。**

```
△先生は眼鏡をかけています。/老师戴着眼镜。
△パーティーに日本人は一人も来ていません。【2009年真題】/聚会上一个日本人也没来
△図書館の本はまだ返していません。【2004年真题】/图书馆的书还没还。
△ドアが閉まっています。【2003年真题/门关着。
```

# ~てある
* が/は + 他动词て形 + ある

**表示有目的性地完成某项动作、行为后,该动作、行为的结果或状态依旧保留着。**

```
△窓が全部開けてあります。【2009年真题/窗户都开着。
△ドアにカレンダーが貼ってあります。【2005年真題】/门上贴着日历。
△そこの机にボールペンが置いてあります。【2000年真题/那边的桌上放着圆珠笔。
```

# ~ないで
* 动词ない形 + ないで

**可表示并列动作的对比,不做前项的动作而是做后项的动作,一般后项的动作出乎意料之外。**

**也可表示一种附加性状况,即在不做前项事情的状况下做后项,而这种情况一般很少出现。**

```
△ボールペンで書かないで、鉛筆で書きます。【2008年真題】不用圆珠笔写,用铅笔写。
△昨日は歯を磨かないで寝ました。【2006年真题昨天没刷牙就睡了。
△わたしはコーヒーに砂糖を入れないで飲みます。【2003年真題】/我喝咖啡不加糖。
```

#  もう~

**后接肯定表达,意为“已经……了”,后面常接动词た形,表示动作的完了。**

```
子どもたちはもう公園に行ったから、うちにはいません。【2000年真題】/孩子们已经去公园了,所以不在家。
```
* 这种情况下「もう」读降调。

**之后接否定表达,意为“已经不……………,再也不………………”等。**

```
△みんながたくさん飲みましたから、もうお酒はありません。【2004年真題】/大家都喝了很多,所以酒已经没了。
△牛乳は全部飲みました。もうありません。【2006年真題】/牛奶全喝完了,已经没了。
△これからもうたばこを吸いません。/从今以后再也不吸烟了。
```

*  这种情况下「もう」也读降调。


**「もう+数量词、副词,意为“再、另外”,表示在原来基础上再累加一些数量或程度。**

```
△もう少し待ったほうがいいですよ。【2008年真題】/再稍微等一下比较好。
△もう少し静かにしてくださいませんか。【2006年真題】/能稍微再安静点吗?
```

* 这种情况下「もう」读升调。
