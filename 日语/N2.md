# 蓝宝书 N2 文法全单元整理（学习笔记版）

> 说明：本文件按书中单元与文法顺序整理。内容为学习笔记式改写：保留文法项目、接续、核心含义、使用注意与自造例句，不逐字复刻原书例句或练习题。

## 记号说明

- **Vる**：动词辞书形；**Vない**：动词ない形；**Vた**：动词た形；**Vて**：动词て形；**Vます stem**：动词ます形去掉「ます」。
- **N**：名词；**Aい**：い形容词；**Na**：な形容词词干。
- **普通形**：动词/形容词/名词句的普通体。名词、な形容词接名词时多用「Nの／Naな」。
- 表格中的例句均为便于记忆的原创例句。

## 第19单元：敬語

### 1. 敬语总体分类

| 类别 | 作用 | 常见形式 | 使用对象 |
|---|---|---|---|
| 尊敬語 | 抬高对方或第三方的动作、状态 | お／ご～になる、れる／られる、特定尊敬动词 | 对方、客人、上级、外部人员 |
| 謙譲語I | 降低自己一方的动作，以抬高动作涉及的对象 | お／ご～する、伺う、拝見する、申し上げる 等 | 自己一方动作涉及尊敬对象 |
| 謙譲語II／丁重語 | 郑重表达自己一方动作，不一定涉及抬高对象 | 参る、申す、いたす、おる、存じる 等 | 对听话人表示郑重 |
| 丁寧語 | 使句子整体礼貌 | です、ます、ございます | 一般礼貌会话 |
| 美化語 | 使词语听起来更郑重、柔和 | お茶、ご飯、お名前、ご住所 | 日常礼貌表达 |

### 2. 尊敬語重点

| 形式 | 接続 | 意味・用法 | 例句 |
|---|---|---|---|
| お／ご～になる | お + Vます stem + になる；ご + 汉语サ变词干 + になる | 抬高对方动作。不能用于过短或习惯上不用的动词。 | 社長はもうお帰りになりました。/ 社长已经回去了。 |
| ～れる／られる | 动词被动态形式 | 可作尊敬，但尊敬程度通常低于「お～になる」。 | 先生は明日来られます。/ 老师明天来。 |
| お／ご～です | お + Vます stem + です；ご + 汉语词 + です | 表示对方状态或正在做某事，常用于通知、询问。 | お客様がお待ちです。/ 客人在等。 |
| お／ご～くださる | お + Vます stem + くださる；ご + 汉语サ变 + くださる | 对方为我方做某事，含感谢。 | ご連絡くださり、ありがとうございます。/ 感谢您联系。 |
| お／ご～なさる | お + Vます stem + なさる；ご + 汉语サ变 + なさる | 尊敬程度较高，正式。 | 先生はどのようにお考えなさいますか。/ 老师您怎么想？ |

### 6. 丁寧語・美化語

| 形式 | 用法 | 例句 |
|---|---|---|
| ～です／～ます | 礼貌句尾，最基础的敬体。 | 明日、会議があります。/ 明天有会议。 |
| ～でございます | 「です」的郑重形式。 | こちらが資料でございます。/ 这是资料。 |
| ございます | 「あります」的郑重形式。 | ご質問はございますか。/ 有问题吗？ |
| お／ご + 名词 | 美化或尊敬。和语多用「お」，汉语词多用「ご」，但有固定例外。 | お名前、ご住所、お茶、ご飯。 |

### 7. 敬语使用注意

- **不要双重敬语过度叠加**：例如「おっしゃられる」一般应改为「おっしゃる」。
- **内外关系**：对外谈自己公司的人时，即使是上司，也通常不用尊敬语抬高自己一方。例如「部長の田中が参ります」。
- **动作主体必须确认**：尊敬语用于对方动作；謙譲語用于自己一方动作。主语搞错会显得不自然。
- **「させていただく」不是万能礼貌**：只有在得到对方许可、受惠于对方时较自然。
- **商务邮件常用句型**：
  - ご確認いただけますでしょうか。/ 能请您确认吗？
  - ご連絡いただき、ありがとうございます。/ 感谢您联系。
  - 何卒よろしくお願い申し上げます。/ 敬请关照。

## 复习建议

1. 先按单元背「接続 + 中文核心意思」。
2. 第二轮把相近表达放在一起比较，如「以上は／上は／からには」。
3. 第三轮只看例句，尝试反推文法含义。
4. 做题时优先检查：接续是否匹配、语气是否书面、结果是好是坏、是否用于人/事/领域/时间。
